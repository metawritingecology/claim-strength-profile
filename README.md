# The Claim-Strength Profile

A candidate corpus-agnostic profile for publisher-authored interpretation limits: evidence classes, strength ceilings, permitted wording, negative frames. Not a confirmed component of any system.

The single conceptual document is [CLAIM_STRENGTH_PROFILE.md](CLAIM_STRENGTH_PROFILE.md). Everything else in this repository is operational scaffolding and does not constitute additional conceptual specification.
